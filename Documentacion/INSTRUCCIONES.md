# 🚀 TAG-R - Instrucciones de Uso

¡Bienvenido a **TAG-R**! Esta herramienta utiliza inteligencia artificial avanzada para organizar tus fotos automáticamente mediante reconocimiento facial.

## 🛡️ SOLUCIÓN: Si Windows bloquea los archivos (SmartScreen)
Dado que has descargado el programa de Internet, Windows puede mostrar mensajes de "Archivo peligroso" o "No ejecutar". Para solucionar esto:

1.  Ejecuta el archivo **`DESBLOQUEADOR_SEGURIDAD.bat`**.
2.  Presiona cualquier tecla. Esto quitará la marca de "descargado de Internet" de todos los archivos de la carpeta.
3.  ¡Listo! Ya puedes usar el programa sin advertencias.

---

## 🛠️ Paso 1: Instalación (Solo la primera vez)
Antes de usar el programa, debes realizar una configuración inicial automática. Este paso instalará Python si no lo tienes y preparará el motor de IA.

1.  Ejecuta el archivo **`1-Instalar_TAG-R.bat`**.
2.  Si el script instala Python, te pedirá cerrarlo y volverlo a ejecutar una vez más.
3.  Espera a que termine (puede tardar de 5 a 15 minutos). Al finalizar, se generará el motor en la carpeta `Sistema_TAG-R`.

## 🏃 Paso 2: Ejecución
Para iniciar la aplicación:

*   Haz doble clic en el archivo **`2-Lanzar_TAG-R.bat`**.
*   Esto abrirá el motor de IA y lanzará automáticamente tu navegador en `http://localhost:8000`.

## 📁 Estructura del Proyecto
Para tu comodidad, hemos organizado los archivos de la siguiente manera:

*   **`Faces/`**: Aquí debes poner carpetas con el nombre de cada persona y 2-3 fotos de su cara.
*   **`Photos/`**: Aquí debes poner todas las fotos que quieres organizar.
*   **`Resultados/`**: Aquí aparecerán tus fotos ya clasificadas en carpetas.
*   **`Documentacion/`**: Guías e instrucciones detalladas.
*   **`Sistema_TAG-R/`**: Archivos internos del motor (No tocar).

## 📊 Cómo organizar tus fotos
1.  Pon las fotos en las carpetas `Faces` y `Photos`.
2.  Inicia el programa con el lanzador.
3.  En la web, simplemente presiona **PROCESAR FOTOS**.
4.  Revisa la carpeta **`Resultados`** en tu computadora.
